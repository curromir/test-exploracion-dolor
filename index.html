🎯 Gold Standard

Clúster de Laslett (Disfunción Sacroilíaca)

Combinación de 5 pruebas de provocación. Requiere ≥3 de 5 positivas.

  • 1. Thigh Thrust (Sens 88% / Espec 75%) - Test individual ancla
  • 2. Distraction Test (Sens 60% / Espec 89%)
  • 3. Sacral Thrust (Sens 63% / Espec 79%)
  • 4. Compression Test (Sens 69% / Espec 69%)
  • 5. Gaenslen Test (Sens 71% / Espec 79%)
Probabilidad post-test: 91% (LR+ 4.16)
🧠 Radiculopatía

Clúster de Wainner (Radiculopatía Cervical)

Diagnóstico de alta certeza para compromiso de raíz cervical.

  • 1. Test de Spurling positivo (SpPin)
  • 2. Test de Distracción positivo (alivio)
  • 3. ULTT 1 (Mediano) positivo (SnNOut)
  • 4. Rotación cervical ipsilateral <60°
4/4 positivas = LR+ 30.3 (Probabilidad >90%)
🦵 Rodilla Aguda

Tríada Diagnóstica del LCA (Rodilla)

Evaluación combinada para desgarro completo del ligamento cruzado anterior.

  • 1. Test de Lachman (Sens 89% / Espec 96%) - El más sensible
  • 2. Pivot Shift Test (Espec 99%) - El más específico
  • 3. Lever Sign (Lelli) (Sens ~100% / Espec ~100%)
Tríada positiva = Diagnóstico en urgencias sin RM en >95%
